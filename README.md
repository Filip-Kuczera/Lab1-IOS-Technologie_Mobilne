# Technologie Mobilne – projekty iOS

- HelloiOS – zadania 2-4 (print, alert, Label "Hello World")
- CompareStrings – zadanie 5 (porównanie stringów)
- Bullseye – gra z suwakiem

Każdy projekt: `cd <folder> && xcodegen && open <folder>.xcodeproj` (macOS + Xcode).
GitHub Actions (.github/workflows/build.yml) sprawdza przy każdym pushu, czy wszystkie trzy się kompilują.
